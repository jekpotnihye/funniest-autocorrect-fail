An entry for the [Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154)
bounty on make.fun: one line under 200 characters that reads as a funny
autocorrect fail and nothing else.

`main.ts` writes the entry to `/output/entry.txt`:

> I'm so sorry for your loss. I'm preying for you and your family in this difficult time.

Run it with Node 22 or later:

```sh
node main.ts
```
